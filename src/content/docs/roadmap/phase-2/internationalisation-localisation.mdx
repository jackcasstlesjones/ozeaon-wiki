## What it involves (8 deliverables)

- Locale routing, detection and user language preference
- String extraction and translation pipeline
- Date, number and currency formatting per locale
- RTL layout support
- Translated-content model for user-generated content and fallbacks
- Translator tooling and review (feeds the PRG translation reward)
- Localised email and notification templates
- hreflang, localised metadata and sitemap entries

## What it involves (9 deliverables)

- For You / Trending / Featured: home page tab shell and per-tab data sources
- Engagement signals: likes, reactions and comments
- Social graph signals from connections and follows
- Scoring pass with trending velocity, decay and basic anti-gaming
- Cold-start handling for new accounts
- Permission-aware filtering: drafts, paywalled, protocol-gated, blocked users
- Featured curation tooling
- Right-hand sidebar: Upcoming, Your Activity
- Precomputation and caching so the feed stays fast

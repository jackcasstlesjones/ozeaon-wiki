## What it involves (6 deliverables)

- Notification types, templates and per-type icons for the five live groups: posts, projects, articles, organisation membership and your own membership
- In-app bell with unread count and read/seen state
- Dropdown panel and dedicated notifications page
- Cross-account addressing so a notification belongs to an organisation or a person
- Realtime delivery so the bell and unread count update the moment something happens
- Backfill hooks so later features register new types without schema change
